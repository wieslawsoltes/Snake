# Snake · 3310 Edition

A playable HTML, JavaScript and WebGPU Snake II recreation with a reference-reconstructed Nokia 3310 handset and reflective monochrome LCD rendering.

The source import, validation, and GitHub Pages deployment are being prepared in this repository. The finished implementation includes mobile keypad and swipe controls, optional thumb controls, local saves, a single-file edition, and a dependency-free static build.

This is an independent clean-room recreation, not Nokia firmware emulation or a claim of physically measured, ROM-exact reproduction. Nokia trademarks belong to their respective owners.
